# واتساب بلا عناء.

Echo بوت واتساب يدير مجموعاتك، ويحمّل وسائطك، ويحمي خصوصيتك، ويجيب بلغة بسيطة، داخل المحادثات التي تستخدمها أصلاً.

## لماذا يختار الناس Echo

- **هاتف أخف.** التنزيلات والتحويلات ومهام الذكاء الاصطناعي تعمل على خوادم Echo، فيوفّر هاتفك البطارية والمساحة.
- **مجموعات تدير نفسها.** حظر الروابط، بطاقات الترحيب، التحذيرات، والموافقة على طلبات الانضمام. اضبطها مرة واحدة.
- **الروابط تصبح ملفات.** أرسل رابط تيك توك أو ريلز أو يوتيوب أو سبوتيفاي وستصلك الوسائط في المحادثة.
- **اطلب كما تكلّم شخصاً.** قل لـ Oblivion ما تحتاجه بلغتك أنت.
- **لا شيء يضيع.** احتفظ بوسائط «العرض لمرة واحدة»، واسترجع الرسائل المحذوفة أو المعدّلة، ورفض المكالمات غير المرغوبة.
- **يعمل دائماً.** يعمل Echo على مدار الساعة كجهاز مرتبط، حتى عندما يرتاح هاتفك.

## مصمم للمشرفين المشغولين

- `.tagall` و`.hidetag` و`.tagcountry +256` لذكر الأشخاص المناسبين
- `.antilink` و`.antiphish` و`.antibot` و`.antispam` لحماية المجموعة
- `.welcome on` للترحيب بكل عضو جديد
- `.approve` و`.reject` لمعالجة كل طلبات الانضمام دفعة واحدة
- `.summarize` و`.timemachine today` للحاق بما فاتك

## تنزيلات تعمل فعلاً

أرسل رابطاً أو اسماً فقط. يصل الصوت مع بطاقة تحوي الغلاف والعنوان والفنان.

```text
.play band for band
.spotify <link>
.tiktok <link>
.video <title>
```

## Oblivion، المساعد داخل Echo

لا حاجة لحفظ الأوامر. اكتب بطبيعتك: «Oblivion، أغلق المجموعة الساعة 10 مساءً» أو «Oblivion، صف لي هذه الصورة».

## ابدأ في دقيقة

1. افتح بوت تيليجرام وأرسل `/pair +رقمك`.
2. في واتساب: **الإعدادات ← الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف** ثم أدخل الرمز المكوّن من 8 خانات.
3. أرسل `.menu` في أي محادثة.
