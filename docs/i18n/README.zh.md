# WhatsApp，省心又轻松。

Echo 是一个 WhatsApp 机器人：帮你管理群组、下载媒体、保护隐私，并用日常语言回答，一切都在你熟悉的聊天里完成。

**[1 分钟上手](#start)** · [控制台](https://echowabot.vercel.app) · [Telegram](https://t.me/devaura_echobot) · [全部命令](../COMMANDS.md)

## 为什么大家选择 Echo

- **手机更轻松.** 下载、转换和 AI 任务都在 Echo 的服务器上运行，你的手机更省电、更省空间。
- **群组自己运转.** 反链接、欢迎卡片、警告和入群申请审批，设置一次就够。
- **链接变文件.** 发送 TikTok、Reel、YouTube 或 Spotify 链接，媒体直接出现在聊天里。
- **像和人聊天一样提需求.** 用你自己的语言告诉 Oblivion 你想做什么。
- **什么都不会丢.** 保存“查看一次”的媒体，找回被删除或被编辑的消息，自动拒接骚扰来电。
- **永远在线.** Echo 作为关联设备 24 小时运行，即使你的手机在休息。

## 为忙碌的管理员而生

- `.tagall`、`.hidetag` 和 `.tagcountry +256`，精准提及合适的人
- `.antilink`、`.antiphish`、`.antibot`、`.antispam` 保护群组
- `.welcome on` 欢迎每一位新成员
- `.approve` 和 `.reject` 一次处理全部入群申请
- `.summarize` 和 `.timemachine today` 快速了解聊天内容

## 真正好用的下载

发送链接或只发名字即可。音频会附带一张卡片（封面、标题、艺人）。

```text
.play band for band
.spotify <link>
.tiktok <link>
.video <title>
```

## Oblivion，Echo 里的助手

不用记命令，直接说：“Oblivion，晚上 10 点关闭群组”或“Oblivion，描述一下这张图片”。

## 1 分钟上手

1. 打开 Telegram 机器人，发送 `/pair +你的号码`。
2. 在 WhatsApp 中进入 **设置 → 已关联的设备 → 关联设备 → 使用手机号码关联**，输入 8 位代码。
3. 在任意聊天中发送 `.menu`。
